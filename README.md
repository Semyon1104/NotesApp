# Pisa-nina

Лёгкое локальное приложение для заметок под Windows. Без аккаунта, облака и подписок: данные хранятся на компьютере.

## Что умеет

- Создавать заметки и вложенные папки, переходить по хлебным крошкам.
- Показывать компактные карточки заметок: крупное название и до трёх категорий в одной строке. Текст и дата на карточке не отвлекают.
- Выбирать заметку чекбоксом с корзиной слева на карточке, а затем удалять выбранное общей кнопкой. Одиночный клик по карточке по-прежнему открывает заметку.
- Перетаскивать заметки и папки и менять их порядок с плавной анимацией без полной перерисовки сетки.
- Удерживать `Alt` при перетаскивании, чтобы создать копию заметки.
- Менять ширину карточек заметок и папок невидимыми боковыми ручками: сетка перестраивается автоматически.
- Открывать заметку сразу в режиме редактирования, без отдельной кнопки с карандашом; под заголовком можно задать отдельный подзаголовок.
- Делать в заметке маркированные и нумерованные списки кнопками панели форматирования.
- Создавать внутри каждой папки двухуровневые категории: главные группы и подкатегории с собственными цветами. Имена категорий и подкатегорий можно менять карандашом — новое имя сразу обновится на всех карточках. Категории видны только на своём уровне и назначаются перетаскиванием на заметки и папки.
- Сортировать карточки по приоритету групп слева направо, затем по порядку подкатегорий. Первая карточка каждой подкатегории главной группы начинает новую строку сетки; изменение порядка групп сразу перестраивает карточки.
- Скрывать и показывать панель категорий кнопкой справа; в свёрнутом состоянии она остаётся на том же месте.
- Вставлять изображения из буфера обмена или перетаскиванием. Картинки автоматически сжимаются в WebP.
- Менять ширину изображения кнопками панели или перетаскиванием ручки в правом нижнем углу.
- Задавать два независимых фона: фото прямо на карточке папки и отдельный фон внутри самой папки. У папки с фото кнопки замены и удаления фото, а также число заметок проявляются при наведении на карточку; шеврона справа от даты нет. Оба фона хранятся вместе с данными приложения.
- Скрывать левую панель кнопкой слева перед «Заметками», а показывать — на том же левом краю верхней панели.
- Надиктовывать русский текст через микрофон; повторное нажатие на микрофон останавливает запись.

## Сохранение

- Во время набора текста приложение не перезаписывает файл данных на каждом изменении.
- Сохранить заметку можно кнопкой с дискетой в верхней панели заметки или сочетанием `Ctrl+S`.
- Горячие клавиши распознаются по физическим клавишам, поэтому `Ctrl+N`, `Ctrl+Shift+N` и `Ctrl+S` работают и в русской раскладке.
- Незавершённые изменения также записываются при закрытии заметки, чтобы не потерять текст.
- Данные всех заметок, папок, изображений и фонов находятся в одном файле:

```text
%LOCALAPPDATA%\PoliaNotes\notes.json
```

## Быстрый запуск

1. Распакуйте архив в любую папку.
2. Запустите `Pisa-nina.exe`.

Портативная версия не устанавливает ярлыки и хранит заметки в `%LOCALAPPDATA%\PoliaNotes\notes.json`.

## Установка с ярлыком на рабочем столе

Запустите `install.cmd` из папки с приложением. Скрипт:

- скопирует программу в `%LOCALAPPDATA%\Programs\Pisa-nina`;
- создаст ярлык `Pisa-nina` на рабочем столе и в меню «Пуск»;
- запустит приложение.

Можно запустить PowerShell вручную:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\install.ps1
```

Если приложение уже открыто, закройте его перед обновлением или установкой.

## Обновление

Приложение не обновляется само. После изменения исходников пересоберите его командой из раздела ниже и снова запустите `install.cmd` либо замените файлы в папке установки. Повторная установка заменяет программу, но не файл `notes.json`, поэтому заметки, папки, картинки и фоны сохраняются.

Для портативной версии достаточно распаковать новый архив поверх старой папки с программой.

## Требования

- Windows 10 или Windows 11, 64-битная.
- .NET Framework 4.8 (входит в Windows 10/11).
- Microsoft Edge WebView2 Runtime. На Windows 11 обычно уже установлен; для Windows 10 при необходимости скачайте Evergreen Runtime с сайта Microsoft.
- Для голосового ввода нужен микрофон и разрешение Windows на его использование. Распознавание запускается на русском языке (`ru-RU`); сервису распознавания может требоваться подключение к интернету.

## Где хранятся данные

```text
%LOCALAPPDATA%\PoliaNotes\notes.json
```

В этом файле лежат папки, заметки, категории, ширины карточек, изображения и фоны (в виде data URL). Для резервной копии закройте приложение и скопируйте `notes.json`. Файл можно перенести на другой компьютер в ту же папку.

## Сборка из исходников

Нужны .NET Framework 4.8 Developer Pack и папка `lib\webview2` с WebView2 SDK (она уже включена в проект).

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Результат:

- `release\Pisa-nina.exe` — рабочая папка приложения;
- `dist\Pisa-nina-portable.zip` — готовый архив для передачи.

Проверка интерфейса и сохранения данных выполняется скриптом `test\e2e.mjs` в тестовом режиме приложения.

## Структура

- `ui\` — HTML, CSS и JavaScript интерфейса.
- `desktop\Program.cs` — WinForms-хост, WebView2 и локальное хранилище.
- `release\` — собранная портативная версия.
- `test\` — E2E-проверки через DevTools Protocol.
